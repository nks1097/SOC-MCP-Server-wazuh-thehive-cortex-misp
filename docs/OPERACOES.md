# ⚙️ Guia de Operações e Monitoramento SOC

Este documento detalha como operar e manter a automação do SOC em ambiente de produção.

---

## 🚀 Execução do Monitoramento Automático

O servidor FastMCP responde diretamente a requisições de IDEs e LLMs enviando notificações e triagem SOAR em tempo real.

### Execução via Linha de Comando:
```bash
python start_mcp.py
```

### Execução da Ponte MCP (Para IDEs e LM Studio):
```bash
python start_mcp.py
```
